# GIM Access Docs

This repository uses a few focused documentation files so teammates can tell what each one is before opening it.

## Main Docs

- `FIRST_READ_THIS.md`
  - beginner-friendly catch-up guide
  - explains what Flutter is, what tools are used, how the pieces fit together, and exactly how to install and run the project
- `STAKEHOLDER_OVERVIEW.md`
  - non-technical and mixed-role overview
  - useful for sales, marketing, entrepreneurship, and first-time collaborators
- `PROJECT_GUIDE.md`
  - primary project setup and development workflow
  - frontend and backend local run instructions
  - team-friendly local URLs and dev notes
- `DEMO_RUNBOOK.md`
  - presentation-day workflow, demo credentials, and team alignment notes
- `backend/BACKEND_GUIDE.md`
  - backend-specific notes for the Express API
  - environment setup, API endpoints, and backend responsibilities
- `raspberry_pi/README.md`
  - Raspberry Pi and camera-vision worker notes
  - explains how the Pi side should fit into the same backend-driven system

## Local-Only Docs

- `TECHNICAL_KNOWLEDGE.md`
  - deeper architecture and schema thinking
  - ignored by Git in the current setup

## Recommended Starting Point

Open `FIRST_READ_THIS.md` first.

## Suggested Reading By Role

- `Developer`
  - start with `FIRST_READ_THIS.md`
  - then read `PROJECT_GUIDE.md`
  - then read `backend/BACKEND_GUIDE.md` if working on the API
- `Sales or Marketing`
  - start with `STAKEHOLDER_OVERVIEW.md`
  - then read `DEMO_RUNBOOK.md`
- `Entrepreneurship / Product Lead`
  - start with `STAKEHOLDER_OVERVIEW.md`
  - then read `DEMO_RUNBOOK.md`
  - then use `FIRST_READ_THIS.md` for technical context
